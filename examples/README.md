# Examples

This directory contains sample traces and skill outputs.

- `traces/github_pr_review_failure.json`: Human correction shows diff inspection was skipped.
- `traces/external_chatbot_policy_failure.json`: Failed evaluation shows stale policy-version usage.
- `traces/workflow_validation_order.json`: Workflow validation order with no candidate signal.
- `traces/specialist_agent_governance_miss.json`: Governance miss corrected by a human reviewer.
- `traces/voice_slot_correction.json`: Voice slot correction for time and location.
- `skills/github_pr_review_discipline.md`: Example exported skill markdown.
- `skills/chatbot_policy_version_check.md`: Example policy-version skill markdown.
