# Operational Lesson: Review Diff Before Approval

## Summary
Inspect changed files before approving a pull request.

## Instructions
- Read changed files before making a recommendation.

## Applies when
- Reviewing pull requests

## Does not apply when
- No code changed

## Anti-patterns
- Approve from metadata alone
