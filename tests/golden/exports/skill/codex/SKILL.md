# Review Diff Before Approval

Inspect changed files before approving a pull request.

## When to use
- Reviewing code changes
- Summarizing pull request risk

## When not to use
- No repository diff is available

## Instructions
- Read the changed files before making a recommendation.
- Call out missing tests when behavior changes.

## Anti-patterns
- Approve based only on the pull request title
