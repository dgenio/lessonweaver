# lessonweaver

lessonweaver turns agent execution traces into reviewed, governed operational
lessons that can be exported to the instruction surfaces teams already use.

Use this site by journey:

- **Get started** for install, quickstart, and release process details.
- **Guides** for the review workflow, cookbooks, and guidance on when not to
  create a skill.
- **Integrations** for supported instruction surfaces and runtime loaders.
- **Reference** for the CLI, public Python API, trace format, adapters, and
  glossary.
- **Project** for architecture, positioning, ecosystem boundaries, and
  repository readiness.
