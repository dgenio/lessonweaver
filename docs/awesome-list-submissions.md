# Awesome-list submission copy

Ready-to-paste entries for submitting lessonweaver to curated community lists,
part of the marketing/reach work in
[#88](https://github.com/dgenio/lessonweaver/issues/88). The actual pull requests
to the external repositories are a follow-up — this file holds the agreed copy so
each submission stays consistent and on-message.

**Framing for every listing:** *governed, human-reviewed skills mined from real
agent failures* — not autonomous self-editing instructions.

## One-line description

> lessonweaver — turn your agent's real failures into reviewed `AGENTS.md` /
> Claude / Copilot skills, deterministically, with a human review gate.

## Target lists and entries

### `awesome-ai-agents`

```markdown
- [lessonweaver](https://github.com/dgenio/lessonweaver) — Mines agent execution
  traces for recurring failures, gates each candidate behind human review, and
  exports approved, governed skills (`AGENTS.md`, Claude, Copilot, Codex, runtime
  snippets). Deterministic core, no LLM calls.
```

### AGENTS.md ecosystem / community resources

```markdown
- [lessonweaver](https://github.com/dgenio/lessonweaver) — Generates `AGENTS.md`
  instruction fragments from reviewed agent failures, with a human-review gate and
  full provenance instead of letting a model rewrite its own instructions.
```

### `awesome-claude` / Claude skills resources

```markdown
- [lessonweaver](https://github.com/dgenio/lessonweaver) — Turns real agent
  failures into reviewed Claude skills / rules / `CLAUDE.md` fragments. Human-gated
  and auditable; no autonomous self-training.
```

### GitHub Copilot customization lists

```markdown
- [lessonweaver](https://github.com/dgenio/lessonweaver) — Exports governed GitHub
  Copilot instruction fragments mined from agent traces and approved through a
  human review gate.
```
